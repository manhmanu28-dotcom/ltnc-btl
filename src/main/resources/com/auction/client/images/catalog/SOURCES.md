# Skin catalog image sources

The bundled catalog contains 65 selected skin designs, with no market prices or
Steam inventory data. It is a sample catalog, not a mirror of the full website.

Names and preview images were collected from these public CSGOSKINS.GG pages:

- https://csgoskins.gg/
- https://csgoskins.gg/weapons/usp-s
- https://csgoskins.gg/weapons/glock-18
- https://csgoskins.gg/weapons/p250

Each entry in `skin-catalog.json` records its original item page and image URL.
Images are bundled unchanged. This project does not claim ownership of the
original artwork or affiliation with CSGOSKINS.GG or Valve.
